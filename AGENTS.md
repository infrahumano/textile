# Agents

## Environment

This project uses [uv](https://docs.astral.sh/uv/) for dependency management and running code.

- Install dependencies: `uv sync`
- Run the CLI: `uv run textile`
- Run a script: `uv run python main.py`
- Run a module: `uv run python -m textile.cli`

Do not use `pip`, `python` directly, or activate the virtualenv manually.
